# superstore-analytics-dashboard
Developed an interactive Superstore Analytics Dashboard using Tableau Public to analyze sales, profit margins, return rates, product categories, customer segments, and regional performance. Created KPI cards, interactive filters, maps, and charts to identify top-selling products and monthly sales trends, supporting data-driven business decisions.
